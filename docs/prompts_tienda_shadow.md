# Prompts para ChatGPT: Tienda Shadow de Bloquevilla (fase 2)

Pega primero el **estilo base** y después cada prompt. Guarda cada imagen como **PNG con fondo transparente** y con el **nombre exacto** que se indica. Mándamelas sueltas (sin zip).

**Truco para que los 7 bloques de un tema salgan iguales:** pide primero el rojo. Cuando te guste, en el mismo chat pide los demás con: *"El mismo bloque exacto, mismo estilo, forma, brillo y tamaño, pero de color [COLOR]."*

**Estilo base (pégalo antes de cada prompt):**
> Estilo de juego móvil casual, ilustración 2D cartoon con volumen suave, colores vivos y saturados, contornos limpios, iluminación desde arriba a la izquierda, como el arte de Bloquevilla (bloques de gelatina brillante). Fondo totalmente transparente, objeto centrado que llena casi toda la imagen, sin texto, sin sombra en el piso.
