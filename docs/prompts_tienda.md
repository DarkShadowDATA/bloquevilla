# Prompts para ChatGPT: imágenes de la Tienda

Pega primero el **estilo base** y después cada prompt. Guarda cada imagen como **PNG con fondo transparente** y con el **nombre exacto** que se indica. Mándamelas sueltas (sin zip).

**Estilo base (pégalo antes de cada prompt):**
> Estilo de juego móvil casual, ilustración 2D cartoon con volumen suave, colores vivos y saturados, contornos limpios, iluminación desde arriba a la izquierda, como el arte de Bloquevilla (pueblo europeo acogedor, bloques de gelatina brillante). Fondo totalmente transparente, objeto centrado, sin texto, sin sombra en el piso.
